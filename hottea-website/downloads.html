Command-Line Installation

Select your target platform for factual CLI instructions.

Note: No official Homebrew Cask has been published yet. Build and launch locally:

Terminal — macOS Build
$git clone https://github.com/Shomay12/hottea.git
$cd hottea && flutter pub get
$flutter run -d macos

Compile the iOS simulator bundle and launch on booted simulator:

Terminal — iOS Simulator
$flutter build ios --simulator
$xcrun simctl install booted build/ios/iphonesimulator/Runner.app
$xcrun simctl launch booted org.hottea.hottea

Install the release APK directly to a connected Android handset or emulator using ADB:

Terminal — ADB Install (Release APK)
$# Check connected Android handset or emulator
$adb devices
$# Install the 56 MB optimized release APK
$adb install -r build/app/outputs/flutter-apk/app-release.apk
$# Launch HotTea on handset
$adb shell monkey -p org.hottea.hottea -c android.intent.category.LAUNCHER 1

Building APK from source: flutter build apk --release (Optimized 56 MB package) or flutter build apk --debug.

Build natively on Ubuntu/Debian:

Terminal — Linux
$sudo apt-get install -y clang cmake ninja-build pkg-config libgtk-3-dev
$flutter build linux

Build with Visual Studio C++ desktop prerequisites:

PowerShell — Windows
>flutter pub get
>flutter build windows
Terminal — Full Test & Build
$git clone https://github.com/Shomay12/hottea.git
$cd hottea
$flutter pub get
$flutter test && flutter analyze

Release Integrity & Verification

Cryptographic SHA-256 hashes confirm file integrity against accidental transmission errors or tampering. Note that a checksum verifies that your downloaded file matches the hash published on GitHub, but is distinct from a cryptographically signed code certificate.

Official Checksum Availability: HotTea will publish a SHA256SUMS.txt manifest accompanying every release tagged on GitHub. Currently, no binary release has been tagged yet.
